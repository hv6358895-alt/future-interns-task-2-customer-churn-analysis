# Future Interns Task 2 – Customer Churn Analysis

## Customer Churn Analysis using Python

### Project Overview

This project analyzes customer churn data using Python to understand the factors that influence customer retention and churn.

The analysis focuses on identifying customer groups with higher churn rates and understanding how different customer characteristics and services are related to churn.

### Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

### Dataset

The project uses a customer churn dataset containing customer demographic information, services, tenure, monthly charges, and churn status.

### Analysis Performed

The following analyses were performed:

1. Churn by Gender
2. Churn by Partner Status
3. Churn by Dependents
4. Churn by Phone Service
5. Churn by Senior Citizen Status
6. Churn by Tenure
7. Monthly Charges vs Churn

### Key Objectives

- Understand overall customer churn behavior
- Identify customer segments with higher churn
- Analyze the relationship between tenure and churn
- Study the effect of monthly charges on churn
- Identify service-related factors associated with customer churn

### Project Files

- `task_2.ipynb` – Complete Python analysis
- `churn_by_gender.png` – Churn analysis by gender
- `churn_by_partner.png` – Churn analysis by partner status
- `churn_by_dependents.png` – Churn analysis by dependents
- `churn_by_phone_service.png` – Churn analysis by phone service
- `churn_by_senior_citizen.png` – Churn analysis by senior citizen status
- `churn_by_tenure.png` – Churn analysis by customer tenure
- `monthly_charges_vs_churn.png` – Monthly charges and churn analysis

### Conclusion

The analysis helps identify customer segments and service characteristics associated with customer churn. These insights can help businesses develop targeted customer retention strategies and reduce churn.
